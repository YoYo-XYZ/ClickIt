# Clickit 2.1.1

ClickIt is now called Clickit. This release updates the name in the extension and its public materials and clarifies free suggestions and subscription credits in the popup.

The extension keeps the same identity, settings, hosted access, and answer behavior. Each Answer press or hotkey handles one visible single-choice question. Clickit does not submit quizzes or advance to another question.

Download and extract **Clickit-v2.1.1.zip**, then load the extracted folder through `chrome://extensions`. Existing unpacked installations can update their current folder and reload the extension.
