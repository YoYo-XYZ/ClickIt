# ClickIt 1.0.1

This release includes the latest Text, Vision, popup, and hosted-service fixes. The attached extension is configured for ClickIt's production hosted service, with 10 free suggestions for eligible new installations and optional monthly subscriptions. You can also use your own TypeSafe or OpenRouter API key.

## Changes since 1.0.0

- Enable hosted Text and Vision access in the downloadable build, using the assigned extension identity recognized by the service.
- Honor saved Text and Vision prompts in hosted answers.
- Simplify Settings with AI access segments and API-key settings that collapse by default.
- Clarify data-sharing consent for API-key access and require local consent when restoring hosted access.
- Improve Vision target validation and tolerate unrelated countdown and cosmetic page updates while canceling changed questions and stale targets.
- Prevent Windows lock-key events from canceling Vision hotkey requests.
- Include subscription management and clearer checkout disclosures.

Each Answer press or hotkey handles one visible single-choice question. ClickIt never submits the quiz or advances to another question. Answers can be wrong.

## Install or update

1. Download and extract **ClickIt-v1.0.1.zip**.
2. Open `chrome://extensions` and enable Developer mode.
3. Select **Load unpacked**, then select the extracted folder containing `manifest.json`.
4. Open ClickIt, review the disclosures, and choose **Start free trial**, or configure your own provider key in Settings.

For an existing unpacked installation, replace the contents of its current extension folder and click **Reload** in `chrome://extensions`. Keep a private backup of your installation access key before replacing or removing an installation. The configured build uses the assigned store identity, so an older installation with a different ID may appear separately and require restoring hosted access in Settings.

This GitHub release does not update the Chrome Web Store listing. Earlier v2.x tags predate the version reset; v1.0.1 continues the current v1.0.0 release line.
