## Permission justifications

- `activeTab`: read or capture only the tab the user invokes ClickIt on.
- `scripting`: inject the single-question detector and safe answer/highlight logic after the user presses Answer.
- `storage`: remember settings, a private installation credential, cached balance, and pending credit acknowledgments.
- Provider hosts: send direct requests in advanced API-key mode.
- Exact deployed ClickIt host: hosted inference, balance lookup, registration, Checkout Session creation, and completion acknowledgments.

No debugger permission, desktop control, persistent all-sites content scripts, or remote executable code is used.

## Privacy disclosure notes

Complete Chrome's current disclosure form from the actual deployed data flow. The extension handles website content, which includes question text, choices, and optional whole-tab screenshots. Those can contain personally identifiable information. It also handles authentication information, including installation credentials and optional provider API keys. The hosted service links purchases and usage to an installation, and Stripe processes billing information.

Declare those applicable categories rather than describing the extension as collecting no data. Explain that data is used for the single stated purpose, fulfillment, fraud prevention, support, and service measurement. The app does not sell user data or use it for advertising. Review the actual provider and platform policies before submitting.
